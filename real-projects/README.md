# Ibrahim Ghaiyth Real Project Archive

This folder contains real standalone portfolio projects by Ibrahim Ghaiyth.

## Projects

- `DijlaTaste-Restaurant` - bilingual restaurant menu, ordering flow, SQLite database, and admin dashboard.
- `TaskNest` - full-stack React and Express task/project manager with JWT auth and SQLite.
- `SentinelDesk` - Python/FastAPI cybersecurity client portal with audit-ready modules.
- `Architect-Maamar` - bilingual AI planning studio built with React, Express, and Groq support.
- `RafidainSuite` - enterprise ERP suite with finance, supply chain, HR, CRM, and project modules.
- `Qassitha` - Iraqi Dinar debt and installment tracker with bilingual UI and SQLite persistence.

Each project keeps its own `README.md`, license, documentation, and run instructions.
